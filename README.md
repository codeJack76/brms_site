# BRMS - Barangay Management System

A Barangay Management System made for Barangays in every municipality in the Philippines

## 📋 Overview

BRMS is a web-based management system designed to help barangay officials efficiently manage their operations, including resident records, certificate issuance, and reporting.

## 🚀 Getting Started

### Prerequisites

- Visual Studio Code (recommended)
- A modern web browser (Chrome, Firefox, Edge, or Safari)
- Live Server extension for VS Code (optional, for development)

### Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/codeJack76/brms_site.git
   cd brms_site
   ```

2. **Open in Visual Studio Code**
   ```bash
   code .
   ```

3. **Install recommended extensions**
   - When you open the project in VS Code, you'll be prompted to install recommended extensions
   - These include Prettier, Live Server, and other helpful tools

4. **Run the project**
   - Option 1: Right-click on `index.html` and select "Open with Live Server"
   - Option 2: Simply open `index.html` in your web browser
   - Option 3: Use the VS Code debugger (F5) with Chrome

## ✨ Features

- **Resident Management**: Maintain comprehensive records of all barangay residents
- **Certificate Issuance**: Generate and issue barangay certificates digitally
- **Reports & Analytics**: View detailed reports and analytics on barangay data
- **Document Management**: Store and manage important barangay documents
